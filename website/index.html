Silly

A memory-safe systems language with no heap.

Python's syntax, Rust-shaped types, and native code by way of C. No allocator, no garbage collector, no lifetime annotations, and a batteries-included standard library.

Get started Take the tour GitHub

Looks like Python. Runs like C.

Every list, string and map lives on a data stack the compiler manages. Growing a value bumps a pointer, and leaving a scope frees everything it made in one store.

enum Shape:
    Circle(f64)
    Rect(w: f64, h: f64)

fn area(s: Shape) -> f64:
    match s:
        case Circle(r): return 3.14159 * r * r
        case Rect(w, h): return w * h

fn main():
    var total = 0.0
    for i in 0..1_000_000:
        # a fresh list each time, freed by
        # the loop itself: no GC, no free()
        let shapes = [Shape.Circle(1.0),
                      Shape.Rect(2.0, i as f64)]
        for s in shapes:
            total += area(s)
    print(f"{total:.1f}")

fn parse_all(xs: &list[str]) -> Result[list[int], str]:
    var out: list[int] = []
    for x in xs:
        out.push(x.parse_int().ok_or(f"not a number: {x}")?)
    return Ok(out)

fn largest[T: Ord + Copy](xs: &list[T]) -> T:
    var best = xs[0]
    for x in xs:
        if x > best:
            best = x
    return best

fn main():
    match parse_all(&["10", "25", "7"]):
        case Ok(nums): print(largest(&nums))     # 25
        case Err(e): print("error:", e)
    let tasks = [spawn(fn() => 6 * 7), spawn(fn() => 2 ** 10)]
    print(join_all(tasks))                    # [42, 1024]

What you get

Safety is checked by the compiler, not paid for at run time.

⚡

No heap, no GC

Allocation is a pointer bump and freeing a scope is a single store. Allocation-heavy code written the obvious way runs like hand-tuned arena code.

🛡️

Memory-safe

No use after free, no out-of-bounds reads, no data races. Moves and borrows are checked at compile time; indexing is always bounds-checked.

🪶

No lifetimes to write

References are only ever function parameters, so every borrow ends when its call returns, and the compiler needs no annotations to prove it.

🐍

Python's syntax

Indentation, f-strings, for x in xs, slices, // and **, with enums, pattern matching, generics and traits on top.

🔋

Batteries included

36 standard modules: json, re, datetime, subprocess, http, argparse and more, plus graphics and a widget toolkit.

🧵

Threads without locks

spawn runs a closure on its own thread with its own stack. Tasks share nothing, so there is nothing to lock and nothing to race.

Fast where it counts

Against idiomatic C++ (g++ -O2) and Rust (rustc -C opt-level=3). All three print identical output.

Windows and widgets, built in

gfx draws anti-aliased shapes and text in a window; ui is an immediate-mode widget toolkit on top of it. Build a GUI.

Try it

You need Python 3.11+ and gcc. There is nothing to build.

# get the compiler
git clone {{repo}}.git
cd silly-lang
export PATH="$PWD/bin:$PATH"

# run a program, or build a native binary
silly run examples/hello.silly
silly build --opt release examples/wordfreq.silly -o wordfreq
